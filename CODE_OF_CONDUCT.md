# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org), version
2.1, as its code of conduct. The full text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In short: respectful treatment is expected in issues, pull requests and any other project
channel; harassment, personal attacks and the publication of other people's private information
are not tolerated.

Incidents are reported privately to the maintainer through
https://github.com/bayplan/bayplan/security/advisories/new (the same channel as
vulnerabilities, which guarantees confidentiality) and are reviewed with discretion.
